# Conformance Predictions

A university lab project at RWTH Aachen University, supervised by Dr. Alessandro Berti.

## What this is

We're building a Python-based tool that combines process mining and machine learning to predict conformance deviations in business processes. The idea is: given a partially observed process case and an event log, can we predict whether a conformance violation will occur later in the process? We use PM4Py for the process mining side and standard ML libraries for the prediction part.
